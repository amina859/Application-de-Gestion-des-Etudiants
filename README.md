# Projet Gestion des Étudiants

## Objectif du projet

Créer une *plateforme web pour gérer les étudiants* : ajouter, modifier, supprimer et consulter leurs informations.

## Fonctionnalités principales

* *Ajouter un étudiant* : nom, prénom, email, téléphone, numéro de carte.
* *Modifier un étudiant* : mettre à jour les informations existantes.
* *Supprimer un étudiant* : retirer un étudiant de la base.
* *Lister et rechercher* : voir tous les étudiants et chercher par nom, prénom ou email.
* *Sécurité* : seul l’administrateur peut gérer les étudiants.

## Technologies utilisées

* *Backend* : Django + Django REST Framework
* *Base de données* : PostgreSQL
* *Frontend* : React
* *Administration* : pgAdmin
* *Déploiement* : Kubernetes

## Résultat attendu

Une plateforme fonctionnelle où l’administrateur peut gérer les étudiants facilement avec une interface web simple et sécurisée.
